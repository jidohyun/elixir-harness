# Status Files

Create one status file per context or namespace.

Example:

```md
# App.ExampleContext Status

- [x] spec_file - `spec/app/example_context.spec.md` exists
- [x] implementation_file - `lib/app/example_context.ex` exists
- [ ] test_file - `test/app/example_context_test.exs` exists
- [ ] tests_passing - focused tests pass
```
